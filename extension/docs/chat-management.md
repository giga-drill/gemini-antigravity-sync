# 对话管理系统使用指南

## 概述

Gemini 聊天导出器现在支持完整的对话管理系统，您可以直接在 Options 面板中管理所有已缓存的聊天记录，包括批量导出、删除和同步到 Gemini web。

## 打开对话管理面板

1. 点击浏览器工具栏中的扩展图标
2. 选择"打开管理面板" (Open Dashboard)
3. 或直接访问 extension options 页面

## 主要功能

### 1. 查看和搜索对话

- **列表展示**: 所有已导出的对话会在表格中显示
- **搜索**: 使用搜索框按对话标题或内容搜索
- **快速信息**: 每条记录显示消息数量、导出时间和模型版本

### 2. 多选操作

#### 全选/取消全选
- 点击工具栏中的 "全选" 复选框可选中所有对话
- 再次点击可取消全选

#### 单个选择
- 点击每条记录左边的复选框选择单个对话
- 已选中的记录会高亮显示

### 3. 批量导出

当选择一个或多个对话后，可执行以下操作：

1. **导出为 Markdown**
   - 点击 "📝 Markdown (n)" 按钮
   - 所有选中的对话会以 Markdown 格式导出

2. **导出为 PDF**
   - 点击 "📄 PDF (n)" 按钮
   - 所有选中的对话会以 PDF 格式导出

数字显示已选择的对话数量。

### 4. 批量删除

#### 启用 Web 同步删除 (推荐)

在删除对话前，您可以选择是否在 Gemini web 中同步删除：

1. **勾选** "同步删除 Gemini 网页中的对话"
   - 删除时会同时从本地缓存和 Gemini web 中删除
   - 更彻底的清理，推荐使用

2. **不勾选**
   - 仅删除本地缓存
   - 对话仍保留在 Gemini 网页中

#### 执行删除

1. 选择一个或多个对话
2. 根据需要启用/禁用 Web 同步选项
3. 点击红色 "🗑️ 删除" 按钮
4. 在确认对话中确认删除
5. 删除过程会显示进度反馈

#### 单个删除

也可以直接点击每条记录右边的 "🗑️" 按钮删除单个对话。

## 工作流示例

### 示例 1: 批量导出选定的对话

```
1. 在搜索框输入关键词找到相关对话
2. 点击多个记录旁的复选框
3. 点击 "📝 Markdown (3)" 导出 3 个对话
4. 浏览器会下载 3 个 .md 文件
```

### 示例 2: 清理旧对话

```
1. 查看 "导出于" 日期，找出旧的对话
2. 选择想要删除的对话
3. 勾选 "同步删除 Gemini 网页中的对话"
4. 点击 "🗑️ 删除 (5)"
5. 确认删除
6. 对话会从本地和 Gemini web 中删除
```

### 示例 3: 导出所有对话并从 Web 清理

```
1. 点击 "全选" 选中所有对话
2. 点击 "📝 Markdown (n)" 导出所有对话
3. 等待导出完成
4. 再次点击 "全选"（如果需要重新加载列表）
5. 勾选 "同步删除 Gemini 网页中的对话"
6. 点击 "🗑️ 删除" 批量删除
```

## 注意事项

### 关于 Web 同步删除

- **前提条件**: 需要打开 Gemini 网页标签页 (https://gemini.google.com)
- **最佳实践**: 在 Gemini 网页标签页中停留，以便扩展可以访问侧边栏
- **失败处理**: 如果 web 删除失败，本地缓存仍会被删除
  - 您可以稍后手动从 Gemini 网页中删除这些对话
  - 或重新勾选选项并重试

### 删除是不可恢复的

- **警告**: 删除操作不可撤销
- 删除前请确保已备份重要对话
- 本地删除的对话可以重新从 Gemini 网页导出

### 搜索功能

- 搜索支持对话标题和消息内容
- 支持正则表达式搜索（高级用户）
- 搜索结果实时更新（有 300ms 防抖）

## 常见问题

### Q: Web 删除失败怎么办？

A: 如果勾选了 "同步删除 Gemini 网页中的对话" 但删除失败，您可以：
1. 手动刷新 Gemini 网页
2. 重新勾选该选项
3. 点击 "🗑️ 删除" 重试
4. 如果仍然失败，可以从 Gemini 网页侧边栏手动删除

### Q: 如何重新导入已删除的对话？

A: 打开 Gemini 网页，找到对话，点击导出按钮。对话会重新添加到本地缓存。

### Q: 批量操作会删除原始的 Gemini 对话吗？

A: 
- **导出**: 不会，仅复制数据
- **删除**: 仅在勾选 "同步删除" 时从 web 删除
  - 不勾选时，只删除本地缓存

### Q: 为什么找不到某个对话？

A: 可能的原因：
1. 对话尚未导出到本地缓存
2. 对话已被删除
3. 搜索关键词不匹配
4. 使用了无效的正则表达式

尝试：
- 清空搜索框查看所有对话
- 从 Gemini 网页重新导出对话
